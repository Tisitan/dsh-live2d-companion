## 安装与兼容性

沿用仓库安装通道：`dsh plugin --profile web add github:Tisitan/dsh-live2d-companion`。附件提供插件 TGZ、完整源码 ZIP 和 SHA256SUMS；本版本不发布到 npm registry。

宿主集成验证版本为 DSH 0.2.1-rc.2。新增鉴权依赖宿主的 `connection.requestRejection`、`authenticatedUrl` 和 `webServer.getOrigin` 接口；旧宿主缺少这些接口时会拒绝服务，请先在测试环境验证兼容性。Electron 安装工具链需要 Node.js ≥22.12。

模型和 Cubism Core 不随版本分发，请保留并使用自己有授权的资源。发布不会自动安装或重启现有 DSH。

Desktop 集成使用官方代理/预载模块及真实前端组成的隔离测试壳，未验完整发行版安装器/更新器。Windows 使用 CI 虚拟桌面和强制缩放；物理 GPU、macOS、Wayland、音频、多屏及运行中系统 DPI 切换仍需对应环境验收。PR #6 的滚动记忆扩展暂未合并。
