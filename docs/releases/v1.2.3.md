## 修复

- 任务完成显示独立的高优先级气泡，使用 `doneHoldMs`。多任务时保留其他任务的主灯状态，避免重复事件和重连快照重复提示。
- 网页挂件气泡避让状态灯与任务灯，长台词限制在挂件宽度内。
- 网页挂件拖动时锁定滚轮缩放；松手、取消、失焦和拖动看门狗收尾后恢复缩放。
- 公共扩展 API 的 `modelList` 实时反映刷新后的列表。
- 手动退出桌宠不再被宿主当作崩溃重拉；保留看门狗恢复与重启收养，并阻止卸载后迟到的恢复操作重新启动进程。
- 独立版 OpenCode 会话调用有明确截止时间和取消信号。语义重排超时回退本地记忆，聊天等调用失败后释放队列，旧会话及迟到结果不混入后续任务。
- 修复国象无法合法吃过路兵时的三次重复局面识别，以及仅剩同色格多个象时的死局识别。补齐升变、逼和、易位、五十回合、重复局面和子力不足回归。
- 修正安装脚本 Node.js 最低版本提示，说明自动日记在回复后空闲一分钟保存，并收窄模型兼容性及拖动范围的过度表述。

## 验证与边界

新增状态、气泡仲裁、任务完成去重、交互收尾、公共 API、宿主监督和 SDK 故障恢复测试。OpenCode SDK 1.19.4 的取消与 HTTP 错误恢复使用本地服务验证，不调用外部模型。CI 在 Linux / Windows、Node 22 / 24 运行回归，并检查真实 Windows Electron 窗口与卡片行为。

隔离环境中已实测 Haru 渲染、完成气泡、多任务状态、原生鼠标拖动/滚轮、模型列表刷新、表情绑定保存与主挂件热更新。真实 Electron 43.8.3 退出经过实际 preload/IPC、PID 清理和 31 秒观察，确认主动退出不会被误拉起；同一测试加入 Windows CI。

测试按其实际覆盖范围解释：软件渲染、虚拟桌面及故障注入不等同于所有物理设备或真实模型服务的验收。完整 DSH Desktop 安装器/更新器、物理 GPU、多屏及运行中系统 DPI 切换、macOS、Wayland和外部模型长期运行仍有环境边界。

## 安装

沿用仓库安装通道：`dsh plugin --profile web add github:Tisitan/dsh-live2d-companion`。模型和 Cubism Core 仍需自备。宿主兼容性要求沿用 1.2.2，Electron 固定 43.8.3、安装工具链要求 Node.js >=22.12。

本次发布不会安装或重启任何现有 DSH；正式环境保持原状。
